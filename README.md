# Adsmarket — ערכת השיווק הרשמית של רשת SAOS

> עיקרון הברזל של התיקייה: **כל טענה שיווקית חייבת להיות מגובה בקבלה משורשרת (txid) או במדידה מתועדת.**
> SAOS לא מבטיחה — SAOS מוכיחה. החומר כאן בנוי לפי אותו עיקרון.

## מה יש בתיקייה

| קובץ | שימוש | קהל יעד |
|---|---|---|
| `index.html` | דף נחיתה מלא (RTL, עצמאי, ללא תלויות חיצוניות) — להעלאה ישירה לכל סטטיק-הוסטינג | כולם |
| `onepager.html` | דף A4 להדפסה/שליחה כ-PDF — סיכום משקיעים ושותפים | משקיעים, שותפים |
| `fact-sheet.md` | מקור האמת: כל המספרים, ה-txids והקישורים המאומתים | צוות שיווק, עיתונאים |
| `pitch.md` | פיץ' 30 שניות / 2 דקות / 5 דקות (עברית + אנגלית) | פגישות, שיחות |
| `social.md` | 12 פוסטים מוכנים ל-X / טלגרם / לינקדאין | קהילה |
| `faq.md` | התנגדויות נפוצות + תשובות כנות | תמיכה, קהילה |
| `brand.md` | קול מותג, פלטת צבעים, מותר/אסור, דיסקליימרים משפטיים | כל מי שכותב בשם SAOS |

## כללי יסוד (לא ניתנים לערעור)

1. **אין הבטחות תשואה.** אף חומר שיווקי לא יציג yield, APR או "הזדמנות השקעה".
2. **כל מספר נמדד מסומן כנמדד; כל מספר תיאורטי מסומן כתיאורטי.** (26,490 ops/sec נמדד · ~2.3B ops/יום תיאורטי).
3. **סטטוסים כנים:** Hive מוצג כ"בהמתנת RC", TRON כ"חמוש-ממתין-מימון". שקיפות היא נכס שיווקי, לא חולשה.
4. **txid או שזה לא קרה.** כל טענת "חי על הרשת" חייבת לקשר לסייר בלוקים.
5. **הערכת שווי/מחירים לא מוצגת בחומר השיווקי** — רק תשתית, הוכחות ויכולות.

## פריסה מהירה של דף הנחיתה

הקובץ `index.html` עצמאי לחלוטין (אין CDN, אין פונטים חיצוניים, אין JS חיצוני).
כל סטטיק-הוסטינג יעבוד: Vercel / Netlify / GitHub Pages / S3 / כל שרת nginx — פשוט להגיש את הקובץ.

## גבולות התיקייה

`Adsmarket` היא תיקיית השיווק בלבד. היא **קוראת** מידע מאומת משאר הריפואים (saos-sovereign-platform, saos-dex, steem, saos-sovereign-foundry) אבל **לא כותבת אליהם לעולם**.
