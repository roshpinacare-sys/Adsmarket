# Identity Verification — דף המוצר הראשון

> המוצר הראשון של SAOS שאפשר להשתמש בו היום. לא מטבע. לא "פלטפורמה". פונקציה אחת שפותרת בעיה אחת — ופותרת אותה עם הוכחה מהשרשרת.

---

## הבעיה, במשפט אחד

יש מיליוני חשבונות ותיקים ב-Steem ו-Hive, ויש עולם חדש של Ethereum ו-Solana — **ואף אחד לא יכול להוכיח ששייכים לאותו אדם**, בלי לבקש ממנו לחשוף מפתחות או לעבור KYC משפיל.

## מה המוצר עושה

שאלה אחת נכנסת:
> "האם החשבון `@username` ב-Steem/Hive וכתובת ה-EVM הזאת — אותו מפתח?"

תשובה אחת יוצאת — **קריאה מתמטית ישירה מהשרשרת עצמה**, לא מהמילים של אף אחד:
1. עוגן הזהות `saos.id.v1` נקרא מהבלוקצ'יין (המשתמש עצמו פרסם אותו שם, פעם אחת)
2. חתימת EIP-191 משוחזרת (ecrecover) לנקודה אליפטית
3. הנקודה מושווה לסמכות הפעילה **החיה** של החשבון ב-Steem וב-Hive, ולכתובת ה-EVM

אם הכול תואם — `PROVEN`, עם מספר הבלוק וקישור לסייר. אם לא — `FAILED`. בשני המקרים זו תשובה אמיתית.

| תחום | כאב | מה המוצר נותן |
|---|---|---|
| משחקי בלוקצ'יין (כמו קלפים על Hive) | ריבוי חשבונות (sybil) שואב תגמולים | הוכחת בעלות בלי מפתחות פרטיים |

## למפתחים — שלוש שורות

> **זמינות נוכחית (כנות):** החבילה חיה בריפו (dist + README, build ירוק) — הפרסום ל-npm registry הוא פעולת בעלים בתהליך. עד הפרסום: התקנה ישירה מהריפו. הפקודה למטה תהפוך פעילה ברגע הפרסום.

```bash
npm i saos-id-verify
```

```ts
import { verifyIdentity } from "saos-id-verify";

const r = await verifyIdentity({
  baseUrl: "https://<your-saos-gateway>",
  apiKey: process.env.SAOS_API_KEY!,
  username: "headcorner"
});
if (r.ok) console.log(r.meta.outcome, r.anchor.block, r.anchor.explorer);
```

- **אפס תלויות** — plain fetch. רץ על Node 18+, Bun, Deno, דפדפנים ו-edge.
- מפתחות API: השרת שומר **רק את ה-SHA-256**; ה-plaintext מוצג פעם אחת.
- שקיפות מדידה: כל תגובה כוללת {used, limit, remaining, resetAt} + headers + latency מדוד.

## טבלת התוצאות (הכנות כמפרט טכני)

| תוצאה | משמעות | נספרת במכסה? |
|---|---|---|
| PROVEN | שרשרת הוכחה מלאה: עוגן → שחזור חתימה → התאמת סמכות חיה פר-שרשרת | כן |
| FAILED | **עבודה אמיתית בוצעה ונכשלה בכנות** (אין עוגן / אין מפתח פעיל). לא שגיאה — תשובה | כן |
| 401 SaosAuthError | מפתח חסר/פגום/מבוטל — fail-closed | לא |
| 429 SaosQuotaError | נגמרה מכסת היממה (UTC) · retryAt = חצות הבא | לא |

גבול כן יחיד: ענף ה-429 מקודד לפי המפרט אך לא נשרף בייצור (שריפה שלו עולה 1,000 קריאות אמיתיות).

## מה המוצר לא (וזה חלק מההגדרה שלו)

- לא מבקש ולא רואה מפתחות פרטיים של אף אחד — ההוכחה נקראת מהשרשרת בלבד
- לא משמורת, לא העברת כספים, לא "wallet connect"
- אפס נתוני דמה: גם בדיקות הפנים (dogfooding) עברו דרך ה-API החי — 3/3 נתיבים
- הלקוח **מסרב להמציא כתובת שרת** — baseUrl חובה, אחרת שגיאה
